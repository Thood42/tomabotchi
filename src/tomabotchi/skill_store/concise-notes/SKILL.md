# Concise notes

Notes live in `notes/` in the workspace, one topic per file, named in kebab-case (`notes/pgvector.md`).

1. Look in `notes/` first. If a note on the topic exists, update it rather than starting another.
2. Lead with the answer in one or two sentences. Then the details, as a short list.
3. Keep it under a screen: about 40 lines. Cut what the reader can look up.
4. Link sources inline, `[name](url)`, next to the claim they support.
5. End with `Updated YYYY-MM-DD` so stale notes are easy to spot.

Say which file you wrote, and what you changed if it already existed.
