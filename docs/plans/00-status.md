- Slice 2 findings and decisions (2026-10-25, from reading Hermes 0.22.5's source in the pinned image):
  - **Leash design changed** from 03's petd `/ask` channel, for the same goal (one gate, asked once):
    - Hermes's `pre_tool_call` hook is capped at 600 s (`_MAX_HOOK_CALLBACK_TIMEOUT_SECS`) and fails closed, so it can't wait hours for the keeper.
    - The leash instead returns `{"action": "block"}` for never, nothing for free, and `{"action": "approve"}` for ask. Hermes's own human gate then asks over ACP `session/request_permission`, with `approvals.timeout` (8 h) as the wait.
    - petd has no `/ask` endpoint; it only bridges stdio↔WebSocket and supervises code-server. Slice 5 does the same for Claude, where the PreToolUse hook returns allow/deny/"ask".
  - **Hermes approvals are `manual`, not `off`:**
    - `off` also bypasses plugin escalations.
    - With `manual`, Hermes's dangerous-command gate still asks, which is exactly slice 4's "dangerous commands always ask". To avoid a double prompt, the leash leaves a dangerous `execute` call under an "ask" rule to that native gate.
  - **Native edit prompts off:** after `session/new` the supervisor sends `session/set_mode dont_ask` (`HermesBrain.session_mode`). Hermes's ACP edit approvals then stay silent, except for sensitive paths like `.env` and SSH keys.
  - **Hermes needs a ≥ 64k context.** Ollama's OpenAI endpoint ignores the model's own context length and silently truncates (measured 9k→2k tokens). The gateway creates and uses the alias `tomabotchi-<model>-ctx64k` via `/api/create` (num_ctx 65536, shares weights). The alias `tomabotchi-qwen3.6-35b-ctx64k` now exists in the host's Ollama.
  - **Runtime:**
    - Built from the pinned `nousresearch/hermes-agent@sha256:9c5561…`, minus chromium and ffmpeg, plus code-server 4.140.0.
    - The Hermes venv's `python` symlink is repointed to the bundled standalone Python 3.14, because upstream pointed it at `/usr/local/bin/python3`, which homes own.
    - Image tags are `<version>-<hash of runtime/ + rules.py>`, so a runtime edit rebuilds.
  - **Permission requests:** a Hermes escalation arrives as a generic execute call whose `rawInput.description` is the leash's message `"<tool> (<kind>): <target>\n---\n<preview>"`. `supervisor.normalize_permission` turns it back into a call card. Hermes's options are allow_once, allow_session (kind allow_always), allow_always, deny (reject_once), deny_always.
  - **Speed:** on this CPU-only host the first turn takes about 3 minutes (13k-token prompt at about 97 tok/s), and generation runs at about 9 tok/s.
  - **Claude adapter for slice 5:** the live package is `@agentclientprotocol/claude-agent-acp` (the `@zed-industries` name stopped at 0.23.1). Pin 0.89.1 (2026-10-10). It needs Node ≥ 22, and Hermes's bundled node 26 is in the runtime. It loads `settingSources ["user","project","local"]`.

- Slice 4 notes (2026-10-25):
  - **"Always allow" is tomabotchi's rule, not the brain's.** `Fleet.answer` adds `rules.rule_for_allow_always` (the tool, or the kind when the brain gave no tool name, under the common folder of its paths) via `with_rule`, rewrites the rules file, and then tells the brain **allow_once**. Hermes and Claude therefore keep no allowlist the rules editor can't see or undo. The button names the rule, for example "Always allow write_file in notes/".
  - **Dangerous commands** (Hermes's own gate; `normalize_permission` marks them `dangerous`) get no Always button, and a hand-made allow_always for one adds no rule.
  - **Rules editor:** `_rules.html` sits under Tools used, with a summary plus a `<details>` form. `PUT /pets/{id}/rules` takes one row per rule; rule "" skips the blank add row and "remove" drops a row. It isn't one of the SSE PARTIALS (re-rendering it would wipe a half-made edit). `Fleet.set_rules` publishes `rules-<id>` only when the rules change.
  - **Blocks reach the server through a file.** Hermes emits no ACP tool events for a call its `pre_tool_call` hook blocks. So the leash appends to `tomabotchi_blocks.jsonl`, next to the rules file in the bind-mounted brain home, and the supervisor drains it on every non-chunk update and at turn end. Each block becomes a tool row "blocked by a rule" and counts in Discipline = asked ÷ (asked + blocked). Slice 5's Claude hook uses the same `rules.record_block`.

- Slice 5 notes (2026-10-25):
  - **Claude Code runs in the same runtime image.**
    - The adapter `@agentclientprotocol/claude-agent-acp@0.89.1`, which brings the Claude Code 2.1.293 binary, is installed by Hermes's npm into `/opt/tomabotchi/claude` (~310 MB).
    - It runs on **code-server's bundled Node 24**, not Hermes's Node 26, because Hermes's Node needs `libatomic.so.1`, which `python:3.12-slim` lacks.
    - The smoke test runs `claude --version` in every home.
  - **The leash is a `PreToolUse` command hook** (`/opt/tomabotchi/bin/leash-claude` → `tomabotchi_leash.claude_hook`), matcher `*`, timeout 60 s.
    - free → `allow`; never → `deny` with the block message (recorded through `rules.record_block`, as for Hermes); ask → `ask`.
    - A dangerous Bash command → `ask` whatever the rules say. Unreadable rules → everything asks.
    - "ask" hands over to Claude's own prompt, which arrives as ACP `session/request_permission`. That prompt is the call card, so the hook never blocks for long.
    - `settings.json` keeps `defaultMode: default` and `disableBypassPermissionsMode: disable`.
  - **The soul is `~/.claude/CLAUDE.md`** (user memory), with a one-line preamble. The rules are `~/.claude/tomabotchi_rules.json`.
  - **Env, not files, points Claude at the gateway:**
    - `ANTHROPIC_BASE_URL=http://tomabotchi:8770/llm/<token>/anthropic` and `ANTHROPIC_API_KEY=<pet token>`. The gateway swaps in the real key.
    - **Every model role** (`ANTHROPIC_MODEL`, `DEFAULT_{HAIKU,SONNET,OPUS}_MODEL`, `SMALL_FAST_MODEL`) is the pet's model. The gateway also pins `body.model` to the pet's choice, because the adapter asks for "opus" by default and the keeper chose the model and its price.
    - On Ollama, the gateway's `/anthropic/v1/messages` goes to Ollama's `/v1/messages` with the 64k alias. `count_tokens` is estimated locally (len/4).
  - **Hatch:** Claude Code is selectable. Anthropic models are disabled with "(needs ANTHROPIC_API_KEY)" when the server has no key, and hatching one without a key is refused.
  - **Permission requests from Claude** carry kind, `rawInput` (Write's `content` shows as the preview) and `locations`, but no tool name. "Always allow" therefore adds a kind-level rule under the folder, for example "Always allow editing files in notes/".
  - **Speed on this host:** Claude Code's system prompt is about 16.7k tokens, and consecutive requests don't share Ollama's prompt cache, so each model call re-prefills for about 3.5 min. A one-file task takes about 8 min on CPU. Fine on Sonnet; slow locally.
